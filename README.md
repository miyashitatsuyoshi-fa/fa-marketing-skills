# ファーストアカウンティング マーケティングチーム Manus スキル集

このリポジトリは、ファーストアカウンティング株式会社のマーケティングチームが Manus で利用するスキル（再利用可能なAIエージェントの作業手順書）を管理するためのものです。

## スキル一覧

| スキル名 | 概要 | トリガーとなる依頼例 |
| :--- | :--- | :--- |
| [event-lp-seo-cro-audit](./SKILL.md) | BtoBイベント・セミナーLPの包括的SEO・CRO監査 | 「このLPのSEO監査をして」「セミナーページのCRO分析をして」 |
| [delivery-model-web-publisher](./delivery-model-web-publisher/SKILL.md) | 宅配便モデル戦略設計書をビジュアルリッチなシングルページWebサイトとして構築・公開 | 「宅配便モデルの結果をWebサイトにして」「デプロイして」「公開して」 |
| [event-lead-followup-generator](./event-lead-followup-generator/SKILL.md) | イベントで名刺交換したリード向けフォローアップ資料（メール文面＋架電スクリプト）をSalesforce由来JSONから生成 | 「フォローアップ資料を作って」「架電スクリプトを作って」「イベント後フォロー」 |

## スキルの使い方

### Manus でスキルを利用する方法

1. このリポジトリの URL を Manus のスキル設定に追加してください。
2. 対象のLPのURLを貼り付けて「SEO・CRO監査をして」と依頼するだけで、スキルが自動的に起動します。

### スキルの追加・更新

新しいスキルを追加する場合は、以下の手順に従ってください。

1. `skill-name/` ディレクトリを作成する
2. `SKILL.md` を作成し、YAML フロントマター（`name`, `description`）と手順を記述する
3. プルリクエストを作成してチームでレビューする
